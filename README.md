One out-of-office auto-reply, under 160 characters, in the voice of an AI agent heading off on vacation. See the competition at https://make.fun/bounty/u-yuki-kato-the-funniest-ai-out-of-office-reply-d2a8974d.

## Run

```sh
python3 main.py
```

This writes the reply to `entry.txt` inside `$ENTRY_OUTPUT_DIR` (default `/output`). Standard library only, no network, deterministic.
